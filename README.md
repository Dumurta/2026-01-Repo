# 🎓 PUC Minas - 3º Período | Ciência da Computação

> **Repositório dedicado ao armazenamento de materiais, projetos e listas de exercícios desenvolvidos durante o primeiro semestre de 2026.**

Este repositório documenta o meu progresso prático e teórico no curso de Ciência da Computação. Aqui, você encontrará os códigos, anotações e trabalhos das disciplinas cursadas neste semestre, abrangendo desde o desenvolvimento de algoritmos avançados até a arquitetura de hardware.

---

## 📚 Disciplinas Cursadas

Neste semestre, o foco está nas seguintes matérias (incluindo frentes teóricas e de laboratório):

* **⚙️ Algoritmos e Estruturas de Dados II (AEDs II)**
    * *Foco:* Estruturas de dados complexas, algoritmos de pesquisa e ordenação, manipulação de arquivos.
    * *Trabalhos Práticos (TPs):* Diretório dedicado às implementações complexas exigidas ao longo do semestre. Todos os códigos são desenvolvidos, testados e otimizados nativamente em ambiente Linux, utilizando o editor         Vim para garantir máxima performance e controle do código.
* **💻 Arquitetura de Computadores I**
    * *Foco:* Organização de computadores, processadores, memória e portas lógicas.
    * *Prática:* Projetos e simulações de hardware utilizando programação em Verilog.
* **🔬 Trabalho Interdisciplinar III: Pesquisa Aplicada**
    * *Foco:* Metodologia científica, pesquisa aplicada e desenvolvimento de um projeto interdisciplinar unindo os conhecimentos do semestre.
* **📐 Cálculo I**
    * *Foco:* Limites, derivadas e suas aplicações fundamentais para a computação.
