SECTION:DISP(BASE, INDEX, SCALE)     SECTION:[BASE + INDEX*SCALE + DISP]

Instruções mais frequentemente usadas

Categoria	    Instruções  	                    Descrição

Movimentaçãor   mov{b,w,(l|d),q}    source, dest    mover de/para
                xchg{b,w,(l|d),q}    dest1, dest2   trocar
                cmpxchg{b,w,(l|d),q} dest1, dest2   comparar e trocar
                push/pop{w,(l|d),q}                 push/pop da pilha (stack)
                movsb                               mover de DS:RSI para ES:(R|E)DI,
                                                    geralmente com prefixo (rep)

Aritmética      add/sub{b,w,(l|d),q} source, dest   somar/subtrair
                imul/mul{b,w,(l|d),q}     formats   multiplicar (com/sem sinal)
                idiv/div{b,w,(l|d),q}     dest      dividir     (com/sem sinal)
                inc/dec/neg{b,w,(l|d),q}  dest      incremento/decremento/negação
                cmp{b,w,(l|d),q} source1, source2   comparar

Lógica          and/or/                             and/or/
                xor/not{b,w,(l|d),q} source, dest   /xor/not lógicos
                sal/sar{b,w,(l|d),q}      formats   deslocamentos (aritméticos)
                shl/shr{b,w,(l|d),q}      formats   deslocamentos (  lógicos  )

Controle        jmp  address                        desvio incondicional
                call address                        salvar    o (R|E)IP na pilha e desviar
                ret                                 retornar ao (R|E)IP salvo pela chamada
                leave                               restaurar   (R|E)BP da pilha; remover stack frame
                j{e,ne,l,le,g,ge} address           desviar caso {=,!=,<,<=,>,>=}
                loop address                        decrementar (R|E)CX; desviar se igual a zero
                rep{e,ne}                           repetir operação com string
                int  number                         interrupção por software
                iret                                retornar de interrupção; voltar EFLAGS da pilha

Outras instruções

AVX/AVX2/AVX-512: 
Para tratar arranjos com acessos a múltiplos dados simultaneamente,
essenciais para multimídia, jogos e IA.

SSE (Streaming SIMD Extensions): 
Para processamento de áudio, vídeo e gráficos 3D.

VT-x (Intel Virtualization Technology): 
Para acelerar a criação e execução de máquinas virtuais e Hyper-V.

AES-NI: 
Para acelerar criptografia e descriptografia por hardware.
