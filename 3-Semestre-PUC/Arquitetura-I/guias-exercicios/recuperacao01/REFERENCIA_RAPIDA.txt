EXERCÍCIO 01 - MAPA DE VEITCH-KARNAUGH
======================================

Mintermos com saída 1: {3, 4, 6, 7, 9, 11, 12}

│ Onde:                                                             │
│   a' = NAND(a,a)                                                  │

│   d' = NAND(d,d)                                                  │

┌─ f.) PoS COM PORTAS NOR (2 entradas) ─────────────────────────────┐

EXERCÍCIO 03 - NAND COMPLEXA
============================

Expressão: nand(nand(nand(a,a),c), nand(nand(a,a),b), nand(nand(b,b),c))

SIMPLIFICAÇÃO:
  nand(a,a) = a'
  nand(b,b) = b'
  
  f = nand(nand(a',c), nand(a',b), nand(b',c))
    = NAND((a'c)', (a'b)', (b'c)')
    = NAND(a+c', a+b', b+c')
    = NOT[(a+c')·(a+b')·(b+c')]
    = (a+c')'·(a+b')'·(b+c')'
    = (a'·c)·(a'·b)·(b'·c)
    = a'·b·c + a'·c·b'  [simplificando]
    = (a'c) + (a'b) + (b'c)

├───┼───┼───┼───┤

│ 0 │ 0 │ 1 │ 1 │ ← a'c
│ 0 │ 1 │ 0 │ 1 │ ← a'b
│ 0 │ 1 │ 1 │ 1 │ ← a'c e a'b
│ 1 │ 0 │ 0 │ 0 │
│ 1 │ 0 │ 1 │ 1 │ ← b'c

EXERCÍCIO 04 - QUINE-McCLUSKEY
==============================

Expressão em notação Quine: 0_0 + _10 + 1_1

MINTERMOS:
  0_0 → 0000 (0), 0100 (4)
  _10 → 0100 (4), 1100 (12)
  1_1 → 1010 (10), 1110 (14)
  Além disso, considerar: 0101 (5)

MINTERMOS TOTAIS: {0, 4, 5, 10, 12, 14}

EXPRESSÃO SoP EQUIVALENTE SIMPLIFICADA:
f = c'd' + bd' + ac + a'b'cd

VERIFICAÇÃO:
  c'd' cobre: 0, 4, 12, 14
  bd' cobre: 4, 12
  ac cobre: 10, 14
  a'b'cd cobre: 5

EXERCÍCIO 05 - CÁLCULOS NUMÉRICOS
=================================

a) FADABACA(16) / 100(4) = ?

   Conversão para decimal:
   FADABACA₁₆ = F×16⁷ + A×16⁶ + D×16⁵ + A×16⁴ + B×16³ + A×16² + C×16 + A
              = 15×268435456 + 10×16777216 + 13×1048576 + 10×65536 
                + 11×4096 + 10×256 + 12×16 + 10
              = 4026531840 + 167772160 + 13631488 + 655360 + 45056 + 2560 + 192 + 10
              = 4208638666₁₀
   
   100₄ = 1×4² + 0×4¹ + 0×4⁰ = 16₁₀
   
   Divisão: 4208638666 ÷ 16 = 263039916.625
   
   Resultado: FA4A5AC₁₆

b) Quociente e resto de 345(8) ÷ 23(4)

   Conversão:
   345₈ = 3×64 + 4×8 + 5 = 192 + 32 + 5 = 229₁₀
   23₄ = 2×4 + 3 = 11₁₀
   
   Divisão: 229 ÷ 11 = 20 com resto 9
   
   Conversão de volta:
   20₁₀ = 24₈ = 110₄
   9₁₀ = 11₈ = 21₄
   
   Resposta: Quociente = 24₈, Resto = 11₈

c) C4(16) - 123(4) em um byte

   Conversão:
   C4₁₆ = 12×16 + 4 = 192 + 4 = 196₁₀
   123₄ = 1×16 + 2×4 + 3 = 16 + 8 + 3 = 27₁₀
   
   Subtração: 196 - 27 = 169₁₀
   
   Conversão para byte:
   169₁₀ = A9₁₆ = 10101001₂
   
   Resposta: A9₁₆ ou 10101001₂
