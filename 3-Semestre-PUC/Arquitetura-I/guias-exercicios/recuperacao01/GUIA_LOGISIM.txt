O que é Logisim?
================
Logisim é um simulador de circuitos digitais que permite:
- Desenhar circuitos lógicos visualmente
- Simular o funcionamento em tempo real
- Testar tabelas verdade
- Converter entre diferentes representações de circuitos

Todas as 6 implementações do Exercício 01 podem ser criadas no Logisim
de forma visual antes de serem sintetizadas em hardware real.

EXERCÍCIO 01 - IMPLEMENTAÇÃO NO LOGISIM
================================================================================

A.) EXPRESSÃO CANÔNICA SoP
─────────────────────────

Passos:
1. Criar uma porta AND para cada minterm com as entradas a, b, c, d
2. Conectar a saída de todos os ANDs a uma porta OR

Mintermos (usar AND de 4 entradas cada):
  • AND(a', b', c, d)      → saída de AND_1
  • AND(a', b, c', d')     → saída de AND_2
  • AND(a', b, c, d')      → saída de AND_3
  • AND(a', b, c, d)       → saída de AND_4
  • AND(a, b', c', d)      → saída de AND_5
  • AND(a, b', c, d)       → saída de AND_6
  • AND(a, b, c', d')      → saída de AND_7

Combinação:
  Conectar AND_1 até AND_7 a uma porta OR de 7 entradas → saída f

Nota: Para NOT, use a porta NOT ou clique com botão direito na entrada

B.) EXPRESSÃO CANÔNICA PoS
──────────────────────────

Passos:
1. Criar uma porta OR para cada maxterm com as entradas a, b, c, d
2. Conectar a saída de todos os ORs a uma porta AND

Maxtermos (usar OR de 4 entradas cada):
  • OR(a, b, c, d)         → saída de OR_1
  • OR(a, b, c, d')        → saída de OR_2
  • OR(a, b, c', d)        → saída de OR_3
  • OR(a, b', c, d')       → saída de OR_4
  • OR(a', b, c, d)        → saída de OR_5
  • OR(a', b, c', d)       → saída de OR_6
  • OR(a', b', c, d')      → saída de OR_7
  • OR(a', b', c', d)      → saída de OR_8
  • OR(a', b', c', d')     → saída de OR_9

Combinação:
  Conectar OR_1 até OR_9 a uma porta AND de 9 entradas → saída f

C.) SIMPLIFICAÇÃO SoP (Mapa de Karnaugh)
────────────────────────────────────────

Expressão simplificada: f = a'cd + ab'cd + abc'd' + a'bd

Circuito:
  
  AND_1: a', c, d          → saída (a'cd)
  AND_2: a, b', c, d       → saída (ab'cd)
  AND_3: a, b, c', d'      → saída (abc'd')
  AND_4: a', b, d          → saída (a'bd)
  
  OR_combinado: AND_1, AND_2, AND_3, AND_4 → saída f

Vantagem: Apenas 4 termos em vez de 7 (redução de 43%)

D.) SIMPLIFICAÇÃO PoS (Mapa de Karnaugh)
────────────────────────────────────────

Expressão simplificada: f = (a+b+c+d)·(a+b+c'+d)·(a'+b+c+d)·(a'+b'+c+d')

Circuito:
  
  OR_1: a, b, c, d         → saída (a+b+c+d)
  OR_2: a, b, c', d        → saída (a+b+c'+d)
  OR_3: a', b, c, d        → saída (a'+b+c+d)
  OR_4: a', b', c, d'      → saída (a'+b'+c+d')
  
  AND_combinado: OR_1, OR_2, OR_3, OR_4 → saída f

E.) IMPLEMENTAÇÃO COM PORTAS NAND (2 ENTRADAS)
───────────────────────────────────────────────

Objetivo: Converter a expressão SoP para usar apenas NAND de 2 entradas

Método (Dupla Negação de De Morgan):
  
  Passo 1: Começar com SoP simplificada
    f = a'cd + ab'cd + abc'd' + a'bd
  
  Passo 2: Aplicar dupla negação
    f = NOT(NOT(a'cd + ab'cd + abc'd' + a'bd))
  
  Passo 3: Aplicar De Morgan (NOT(A+B) = NOT(A)·NOT(B))
    f = NOT((NOT(a'cd))·(NOT(ab'cd))·(NOT(abc'd'))·(NOT(a'bd)))
  
  Passo 4: Para cada termo, usar dupla negação novamente
    NOT(a'cd) = NAND(NAND(a',c),NAND(d,d))  [usando dupla negação]
  
  Circuito no Logisim:
    1. Converter cada a' para NAND(a,a)
    2. Cada AND interno se torna NAND
    3. Combinar com NANDs de 4 entradas
    4. Saída final NAND de 4 entradas

F.) IMPLEMENTAÇÃO COM PORTAS NOR (2 ENTRADAS)
──────────────────────────────────────────────

Objetivo: Converter a expressão PoS para usar apenas NOR de 2 entradas

Método (similar ao NAND, usando De Morgan):
  
  Expressão PoS: f = (a+b+c+d)·(a+b+c'+d)·(a'+b+c+d)·(a'+b'+c+d')
  
  Passo 1: Aplicar dupla negação
    f = NOT(NOT((a+b+c+d)·(a+b+c'+d)·(a'+b+c+d)·(a'+b'+c+d')))
  
  Passo 2: Aplicar De Morgan (NOT(A·B) = NOT(A)+NOT(B))
    f = NOT((NOT(a+b+c+d)) + (NOT(a+b+c'+d)) + (NOT(a'+b+c+d)) + (NOT(a'+b'+c+d')))
  
  Passo 3: NOT(a+b) = NOR(a,b)
  
  Circuito no Logisim:
    1. Converter a' para NOR(a,a)
    2. Cada termo OR se torna múltiplos NOR de 2 entradas
    3. Combinar com NOR final
    4. Usar inversões conforme necessário

PROCEDIMENTO GERAL PARA CRIAR UM CIRCUITO NO LOGISIM:
================================================================================

1. INICIALIZAR LOGISIM
   - Abrir Logisim
   - File → New (ou Ctrl+N)
   - Main circuit será criado automaticamente

2. ADICIONAR COMPONENTES
   - À esquerda estão as paletas de componentes
   - Usar Wiring para adicionar portas AND, OR, NOT, NAND, NOR
   - Usar Input/Output para adicionar entradas (a, b, c, d) e saída (f)

3. CONECTAR COMPONENTES
   - Clicar e arrastar para conectar os fios entre componentes
   - Pressionare ESC para terminar de conectar

4. TESTAR
   - Simuesto menu: Simulate → Simulate Enabled (ou Ctrl+E)
   - Usar Mode → Poke Tool para mudar valores de entrada
   - Observar as saídas em tempo real

5. VALIDAR COM TABELA VERDADE
   - Simular para cada combinação de a, b, c, d
   - Registrar os resultados
   - Comparar com a tabela verdade esperada

6. SALVAR
   - File → Save (ou Ctrl+S)
   - Nomear como: recuperacao_ex01a.circ, etc.

EXEMPLO PRÁTICO: IMPLEMENTAR EX 01C NO LOGISIM
================================================================================

Expressão: f = a'cd + ab'cd + abc'd' + a'bd

Passo 1: Adicionar Entradas
─────────────────────────────
  • Wiring → Input (4 vezes)
  • Nomear: a, b, c, d
  • Arranjar na esquerda, verticalmente

Passo 2: Adicionar Portas NOT (para inversões)
───────────────────────────────────────────────
  • Wiring → NOT (3 vezes)
  • Conectar: 
    - a → NOT_1 (para a')
    - b → NOT_2 (para b')
    - c → NOT_3 (para c')
    - d → (podemos criar d' se necessário)

Passo 3: Adicionar Portas AND (um para cada termo)
───────────────────────────────────────────────────
  • Wiring → AND (4 vezes)
  
  AND_1 (para a'cd):
    - Entrada 1: saída de NOT_1 (a')
    - Entrada 2: c
    - Entrada 3: d
    - (clique direito na entrada 4 para remover)
  
  AND_2 (para ab'cd):
    - Entrada 1: a
    - Entrada 2: saída de NOT_2 (b')
    - Entrada 3: c
    - Entrada 4: d
  
  AND_3 (para abc'd'):
    - Entrada 1: a
    - Entrada 2: b
    - Entrada 3: saída de NOT_3 (c')
    - Entrada 4: saída de NOT para d'
  
  AND_4 (para a'bd):
    - Entrada 1: saída de NOT_1 (a')
    - Entrada 2: b
    - Entrada 3: d

Passo 4: Adicionar Porta OR Final
──────────────────────────────────
  • Wiring → OR (1 vez)
  • Conectar as 4 saídas dos ANDs às 4 entradas do OR

Passo 5: Adicionar Saída
────────────────────────
  • Wiring → Output
  • Nomear: f
  • Conectar a saída do OR final

Passo 6: Testar
───────────────
  • Ctrl+E para habilitar simulação
  • Usar ferramentas de entrada para variar a, b, c, d
  • Registrar os 16 casos (0000 até 1111)
  • Verificar se correspondem à tabela verdade

================================================================================
DICAS IMPORTANTES:
==================

1. ORGANIZAÇÃO
   - Alinhe os componentes na horizontal
   - Agrupe por tipo (entradas, processamento, saídas)
   - Use rótulos nos fios para clareza

2. VERIFICAÇÃO
   - Sempre simule os casos de extremo: 0000, 1111
   - Compare com SoP canônico (devem ser iguais)
   - Use subcircuitos para reutilizar componentes

3. NEGAÇÃO
   - Para NOT c: pode usar gate NOT ou clicar direito na entrada
   - Para NAND(c,c): cria NOT de forma compacta

4. EXPORTAR
   - Pode exportar circuito como imagem (Ctrl+Shift+E)
   - Salvá-lo em PDF para documentação

5. SIMULAÇÃO
   - Slow clock mode para visualizar propapagação
   - Ver valores dos fios durante simulação
   - Usar Combinatorial Analysis para tabela completa

COMPARAÇÃO: TRÊS FORMAS DE IMPLEMENTAÇÃO
=========================================

┌─ FORMA CANÔNICA SoP (7 termos) ──────────────────────────────────┐
│ Vantagem: Fácil de entender, segue minterm table                 │
│ Desvantagem: 7 portas AND + 7 entradas na OR = muita complexidade│
│ Uso: Referência, validação, testes iniciais                      │
└──────────────────────────────────────────────────────────────────┘

┌─ FORMA SIMPLIFICADA SoP (4 termos) ───────────────────────────────┐
│ Vantagem: Menos componentes, mais eficiente                       │
│ Desvantagem: Exige análise com Karnaugh                           │
│ Uso: Implementação prática, hardware real                         │
└──────────────────────────────────────────────────────────────────┘

┌─ COM PORTAS NAND (2 entradas) ────────────────────────────────────┐
│ Vantagem: Apenas um tipo de porta (universal)                     │
│ Desvantagem: Mais portas devido a conversão                       │
│ Uso: Implementação em VLSI, síntese de hardware                   │
└──────────────────────────────────────────────────────────────────┘
